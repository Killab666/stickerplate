# StickerPlate

Victoria Australia number plate designer + freeform custom stickers.

## Live demo

Enable **GitHub Pages**:
1. Repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save

Site URL: **https://killab666.github.io/stickerplate/**

## Features

- **Victoria Plates**: Standard, Slimline, Black Slim, Heritage
- Slogan *Victoria – The Education State*
- EU-style side band option
- **Custom Stickers**: shapes + styles
- Live preview + high-res PNG download
- Shareable design links

## Local use

Open `index.html` in any browser — no build step required.
